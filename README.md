# SpaceX Data Science Capstone

This repository contains the complete IBM Data Science Capstone project focused on predicting Falcon 9 first-stage landing success.

## Deliverables

- Final PDF report
- PowerPoint presentation
- Project datasets
- Chart-generation script
- Exported charts and model evaluation visuals

## Project scope

The analysis covers data collection, data wrangling, exploratory analysis, SQL, interactive mapping, dashboard development, and machine-learning classification.
